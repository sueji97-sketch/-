[이미지 교체 안내 가이드]

이 폴더(public/images/projects/)는 포트폴리오 웹사이트의 프로젝트 배너에 들어갈 실제 이미지를 보관하는 곳입니다.

현재 웹사이트는 이미지가 없더라도 파일명이 표기된 세련된 플레이스홀더(Placeholder)로 안전하게 표시되도록 구현되어 있습니다.

추후 실제 사진을 넣으실 때는 아래 파일명과 동일하게 이미지를 이 폴더에 복사/붙여넣기 하시면 웹사이트에 즉시 반영됩니다:

- project-01.jpg : 사계절 생태 놀이 활동 사진 (가로 비율 권장: 16:9 또는 4:3)
- project-02.jpg : 그림책 놀이 / 감정 카드 교구 활동 사진
- project-03.jpg : 부모 참여 수업 / 프레젠테이션 진행 사진
- project-04.jpg : 어린이 소방대원 / 안전 교육 훈련 사진
- project-05.jpg : 누리과정 관찰일지 / 평가 서식 및 학급 운영 사진

* 팁: png, webp 등 다른 확장자를 사용하실 경우 src/data/projects.json 에서 파일명을 수정해주시면 됩니다.
